# Учебный frontend-проект

## Описание
Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».
Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта
- `index.html` — главная страница: новости, первый экран, популярные товары, окно заказа;
- `news.html` — новости сервера, переход к новости по якорю (`:target`);
- `donate.html` — каталог товаров (лавка) с быстрым просмотром товара;
- `product.html` — страница товара «Набор „Новичок“»;
- `cart.html` — корзина и оформление заявки;
- `launcher.html` — лаунчер, системные требования и контакты;
- `css/style.css` — файл стилей;
- `js/main.js` — окно заказа, валидация формы, корзина, быстрый просмотр, копирование IP;
- `fonts/` — шрифт Minecraft Rus;
- `images/` — папка для изображений;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Постановка контрольной работы №1
Тема контрольной работы №1: «HTML и CSS: разработка многостраничного сайта».
В рамках контрольной работы необходимо разработать многостраничный HTML/CSS-сайт интернет-магазина или каталога услуг.
Проект должен включать:
- главную страницу;
- страницу каталога;
- страницу карточки товара или услуги;
- страницу оформления заявки;
- страницу контактов;
- семантическую HTML-разметку;
- внешний CSS-файл;
- базовую навигацию;
- оформление основных блоков страницы.

## История выполнения
- Практическая работа 1: создан Git-репозиторий, опубликован проект на GitHub Pages.
- Практическая работа 2: создан HTML-каркас стартовой страницы и выполнено базовое CSS-оформление.
- Практическая работа 3: добавлена форма заказа в модальном окне `dialog`, валидация полей на JavaScript и передача выбранного товара через `data-product` в скрытое поле.
- Практическая работа 4: цвета вынесены в CSS-переменные в `:root` (тёмная тема), добавлены состояния `:hover`, `:active`, `:focus-visible` и `:disabled`; кнопка отправки заявки активна только после согласия с условиями.
- Практическая работа 5: добавлены страницы новостей, лавки (каталог), товара, корзины и лаунчера (контакты); единая навигация, хлебные крошки, уникальные `title` и `meta description`, якорные ссылки и подсветка новости через `:target`.
- Практическая работа 6: главная страница перестроена на CSS Grid (преимущества, товары, режимы) и Flexbox (меню, карточки, FAQ); в лавке добавлен блок фильтров (поиск, категории, сортировка) и раскладка каталога через `grid-template-areas`; появление блоков при прокрутке.
- Практическая работа 7: проведён аудит классов по БЭМ — вложенные селекторы вида «класс + тег» заменены на элементы (\hero__fact-icon`, `form__checkbox`, `product__item`, `details__item`, `filters__radio`) и модификатор `form__input--textarea`; стилизации через id и inline-стилей нет.`
